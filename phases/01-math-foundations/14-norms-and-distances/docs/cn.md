## The Problem

你有两个向量。可能是词嵌入,可能是用户画像,可能是像素数组。你得知道: 它们多接近?

答案完全看你选哪个距离函数。两个数据点在一个度量下是最近邻,在另一个度量下可能天各一方。KNN 分类、推荐系统、向量数据库、聚类算法、loss 函数 —— 全靠这个选择。选错了,模型就在优化错的东西。

没有"全宇宙最好"的距离。L2 适合空间数据,余弦相似度统治 NLP,Jaccard 处理集合,编辑距离处理字符串,马氏考虑相关性,Wasserstein 搬概率质量。每个都编码了对"相似"的不同假设。

这节课把每个主流距离从零写出来,告诉你啥时候用哪个,演示同样数据在不同度量下能产出完全不同的最近邻。

## The Concept

### 范数:测向量大小

范数衡量向量的"大小"。两个向量的距离函数都能写成它们差的范数: d(a, b) = ||a - b||。所以懂范数就懂距离。

### L1 范数(曼哈顿距离)

L1 范数把各分量绝对值求和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

它叫曼哈顿距离是因为它衡量你在城市网格上能走多远,只能沿轴走。不能斜着穿。

```
点 A = (1, 1)
点 B = (4, 5)

L1 距离 = |4-1| + |5-1| = 3 + 4 = 7

在网格上,你走 3 个街区向东再 4 个街区向北。
```

啥时候用 L1:
- 高维稀疏数据(文本特征、one-hot 编码)
- 想要对离群点鲁棒(单个巨大差不主导)
- 特征选择问题(L1 正则促稀疏)

跟 L1 正则(Lasso)的关系: 加 ||w||_1 到 loss 函数里惩罚权重绝对值之和。这把小的权重直接压到 0,做自动特征选择。L1 惩罚在权重空间形成菱形约束区,菱形的角在轴上,有些权重是 0。

跟 loss 函数的关系: 平均绝对误差(MAE)是预测和目标的平均 L1 距离。它对所有误差线性惩罚,比 MSE 对离群点更鲁棒。

### L2 范数(欧氏距离)

L2 范数是直线距离。各分量平方和的平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这是几何课学的距离。n 维的勾股。

```
点 A = (1, 1)
点 B = (4, 5)

L2 距离 = sqrt((4-1)² + (5-1)²) = sqrt(9 + 16) = sqrt(25) = 5.0

直线,斜穿过网格。
```

啥时候用 L2:
- 低到中等维度的连续数据
- 特征尺度可比时
- 物理距离(空间数据、传感器读数)
- 像素级的图像相似度

跟 L2 正则(Ridge)的关系: 加 ||w||_2² 到 loss 惩罚大权重。不像 L1,它不把权重压到 0。它把所有权重按比例往 0 方向缩。L2 惩罚形成圆形约束区,轴上没角。权重变小但很少真到 0。

跟 loss 函数的关系: 均方误差(MSE)是 L2 距离平方的平均。平方让大误差被罚得比重小误差重。

```
MAE (L1 loss):  |y - y_hat|         线性惩罚。对离群点鲁棒。
MSE (L2 loss):  (y - y_hat)²       二次惩罚。对离群点敏感。
```

### Lp 范数:通用家族

L1 和 L2 是 Lp 范数的特殊情况:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同的 p 产生不同形状的"单位球"(距原点 1 的所有点):

```
p=1:    菱形       (角在轴上)
p=2:    圆/球      (通常的圆球)
p=3:    超椭圆     (圆角方)
p=inf:  方/超立方  (边沿轴)
```

### L-无穷 范数(切比雪夫距离)

p 趋向无穷时,Lp 范数收敛到最大绝对分量。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点之间的距离由它们"差异最大"的那一维决定。其他维都被忽略。

```
点 A = (1, 1)
点 B = (4, 5)

L-inf 距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

啥时候用 L-infinity:
- 任何单维的最坏偏差很重要时
- 棋盘(国际象棋的王走 L-infinity: 任意方向走一步都是 1)
- 制造公差(每维都必须在范围内)

### 余弦相似度和余弦距离

余弦相似度衡量两个向量的夹角,忽略大小。

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

从 -1(反方向)到 +1(同方向)。垂直向量余弦相似度为 0。

余弦距离把它换成距离: cosine_distance = 1 - cosine_similarity。范围从 0(同方向)到 2(反方向)。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

为啥余弦主导 NLP 和嵌入: 在文本里,文档长度不该影响相似度。一篇关于猫的文档,比另一篇关于猫的文档长一倍,还应该"相似"。余弦相似度忽略大小(长度),只关心方向。两篇词分布一样但长度不同的文档指向同方向,余弦相似度 1.0。

啥时候用余弦相似度:
- 文本相似度(TF-IDF 向量、词嵌入、句嵌入)
- 任何"大小是噪声、方向是信号"的领域
- 推荐系统(用户偏好向量)
- 嵌入搜索(向量数据库几乎都用余弦或点积)

### 点积相似度 vs 余弦相似度

两个向量的点积是:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

余弦相似度是点积除以两个大小。当两个向量都已经单位化(大小 = 1),点积和余弦相似度就一样了。

```
如果 ||a|| = 1 且 ||b|| = 1:
    a . b = cos(夹角)
```

不同的时候: 点积包含大小信息。更大的向量得点积分更高。这在某些检索系统里有意义,你想让"热门"项目排得更靠前。大小就是隐含的质量或重要性信号。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

方向上两者一致,但点积还反映大小。
```

实际中:
- 想要纯方向相似度就用余弦相似度
- 大小带信息就用点积
- 很多向量数据库(Pinecone、Weaviate、Qdrant)让你在两者间选
- 嵌入已经 L2 归一化过的话,选哪个没区别

### 马氏距离

欧氏距离把所有维度一视同仁。但如果你的特征有相关或尺度不同,L2 会给误导性结果。

马氏距离考虑数据的协方差结构。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中 S 是数据的协方差矩阵。

直观: 马氏距离先把数据去相关并归一化(白化),然后在变换空间算 L2。如果 S 是单位矩阵(无相关、单位方差特征),马氏距离退化成欧氏距离。

```
例子: 身高和体重相关。
一个 6'2" 180 lbs 的人不奇怪。
一个 5'0" 180 lbs 的人奇怪。

欧氏距离可能说它们离均值一样远。
马氏距离正确识别第二个是离群点
因为它考虑了身高-体重的相关性。
```

啥时候用马氏距离:
- 离群点检测(距均值马氏距离大的点就是离群点)
- 特征尺度不同且有相关性时分类
- 有足够数据估可靠的协方差矩阵
- 制造质量控制(多变量过程监控)

### Jaccard 相似度(用于集合)

Jaccard 相似度衡量两个集合的重叠。

```
J(A, B) = |A ∩ B| / |A ∪ B|
```

从 0(无重叠)到 1(完全一样的集合)。Jaccard 距离 = 1 - Jaccard 相似度。

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

交集 = {cat, fish}         大小 = 2
并集 = {cat, dog, fish, bird, snake}  大小 = 5

Jaccard 相似度 = 2/5 = 0.4
Jaccard 距离 = 0.6
```

啥时候用 Jaccard:
- 比较标签、类别、特征的集合
- 基于"词出现"(非频率)的文档相似度
- 近似重复检测(Jaccard 的 MinHash 近似)
- 比较二值特征向量(出现/不出现数据)
- 评估分割模型(Intersection over Union = Jaccard)

### 编辑距离(Levenshtein 距离)

编辑距离是把一个字符串变成另一个所需的最少单字符操作数。操作是: 插入、删除、替换。

```
"kitten" -> "sitting"

kitten -> sitten  (替换 k -> s)
sitten -> sittin  (替换 e -> i)
sittin -> sitting (插入 g)

编辑距离 = 3
```

用动态规划算。填一张表,entry (i, j) 是 A 串前 i 字符和 B 串前 j 字符的编辑距离。

```
         ""  s  i  t  t  i  n  g
     ""   0  1  2  3  4  5  6  7
     k    1  1  2  3  4  5  6  7
     i    2  2  1  2  3  4  5  6
     t    3  3  2  1  2  3  4  5
     t    4  4  3  2  1  2  3  4
     e    5  5  4  3  2  2  3  4
     n    6  6  5  4  3  3  2  3
```

啥时候用编辑距离:
- 拼写检查和纠正
- DNA 序列比对(带权操作)
- 模糊字符串匹配
- 杂乱文本数据去重

### KL 散度(不是距离,但当距离用)

KL 散度衡量一个概率分布跟另一个差多少。Lesson 09 讲过,它属于这章是因为大家把它当"距离"用,虽然它不是。

```
D_KL(P || Q) = Σ p(x) * log(p(x) / q(x))
```

关键性质: KL 散度不对称。

```
D_KL(P || Q) != D_KL(Q || P)
```

这意味着它不满足距离度量的基本要求。它也不满足三角不等式。它是发散量,不是距离。

正向 KL(D_KL(P || Q))是"求均": Q 试图覆盖 P 的所有模态。
反向 KL(D_KL(Q || P))是"求模": Q 聚焦在 P 的单一模态上。

看到 KL 散度的地方:
- VAE(ELBO 里的 KL 项把潜分布推向先验)
- 知识蒸馏(学生试图匹配教师的分布)
- RLHF(KL 惩罚让微调模型不离基模型太远)
- 策略梯度方法(约束策略更新)

### Wasserstein 距离(推土机距离)

Wasserstein 距离衡量"把一个概率分布变成另一个所需的最少工作量"。想象: 一个分布是一堆土,另一个是坑,你得搬多少土、多远。

```
W(P, Q) = 对所有传输方案 gamma 取下确界 E[d(x, y)]
```

对 1D 分布,简化为累积分布函数绝对差的积分:

```
W_1(P, Q) = ∫ |CDF_P(x) - CDF_Q(x)| dx
```

为啥 Wasserstein 重要:
- 它是真度量(对称,满足三角不等式)
- 即使分布不重叠也给梯度(KL 散度就到无穷了)
- 这个性质让它在 Wasserstein GAN(WGAN)里很关键,解决了原版 GAN 的训练不稳

```
不重叠的分布:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL 散度: 无穷(0 的对数)
Wasserstein: 4(把所有质量搬 4 个 bin)

Wasserstein 给有意义的梯度。KL 不给。
```

啥时候用 Wasserstein:
- GAN 训练(WGAN、WGAN-GP)
- 比较可能不重叠的分布
- 最优传输问题
- 图像检索(比颜色直方图)

### 为啥不同任务需要不同距离

| 任务 | 最佳距离 | 为啥 |
|------|--------------|------|
| 文本相似度 | 余弦 | 大小是噪声,方向是意义 |
| 图像像素比较 | L2 | 空间关系重要,特征尺度可比 |
| 稀疏高维特征 | L1 | 鲁棒,不放大概率小的差异 |
| 集合重叠(标签、类别) | Jaccard | 数据天然是集合,不是向量 |
| 字符串匹配 | 编辑距离 | 操作对应人编辑的直觉 |
| 离群点检测 | 马氏 | 考虑特征相关和尺度 |
| 比较分布 | KL 散度 | 衡量用 Q 代替 P 损失的信息 |
| GAN 训练 | Wasserstein | 即使不重叠也给梯度 |
| 嵌入(向量库) | 余弦或点积 | 嵌入训练时把意义编码到方向里 |
| 推荐 | 点积 | 大小可以编码热度或置信度 |
| DNA 序列 | 加权编辑距离 | 不同核苷酸对的替换代价不同 |
| 制造 QC | L-infinity | 任一维的最坏偏差要紧 |

### 跟 Loss 函数的联系

Loss 函数就是"预测 vs 目标"上的距离函数。

```
Loss 函数         用的距离                行为
MSE               L2 平方                重罚大误差
MAE               L1                     平均罚所有误差
Huber loss        大误差用 L1,          兼得: 鲁棒离群点,零附近梯度平滑
                  小误差用 L2
交叉熵           KL 散度                衡量分布失配
Hinge loss        max(0, margin - d)    只罚低于 margin 的
Triplet loss      L2 (通常)             拉近正样本,推远负样本
Contrastive loss  L2                     相似对近,不相似对超 margin
```

### 跟正则化的联系

正则化把权重的范数惩罚加到 loss 函数上。

```
L1 正则 (Lasso):   loss + λ * ||w||_1
  -> 稀疏权重。有些权重真变 0。
  -> 自动特征选择。
  -> 解有角(在 0 处不可微)。

L2 正则 (Ridge):   loss + λ * ||w||_2²
  -> 小权重。所有权重往 0 缩。
  -> 不做特征选择(没东西真到 0)。
  -> 解处处平滑。

Elastic Net:         loss + λ_1 * ||w||_1 + λ_2 * ||w||_2²
  -> L1 的稀疏 + L2 的稳定性。
  -> 相关特征的组一起留或一起扔。
```

为啥 L1 产生稀疏但 L2 不: 想象 2D 权重空间里的约束区。L1 是菱形,L2 是圆。loss 函数的等高线(椭圆)最可能碰菱形于角(某权重是 0),碰圆于平滑点(两权重都非零)。

### 最近邻搜索

每个距离函数都隐含一个最近邻搜索问题: 给定一个查询点,在数据集中找最近的点。

精确最近邻搜索,数据集 n 个点 d 维,每次查询 O(n * d)。大数据集上太慢。

近似最近邻(ANN)算法用一点点精度换巨大的速度提升:

```
算法                方法                         谁在用
KD-trees            按轴划分空间                 scikit-learn (低维)
Ball trees          嵌套超球                    scikit-learn (中维)
LSH                 随机哈希投影                 近似重复检测
HNSW                分层可导航小世界图           FAISS、Qdrant、Weaviate
IVF                 倒排文件 + 基于簇的搜索     FAISS (十亿级)
Product quant.      压缩向量,在压缩空间搜      FAISS (内存受限)
```

HNSW(分层可导航小世界)是现代向量数据库的主流算法。它建一个多层图,每个节点连到它的近似最近邻。搜索从顶层(稀疏,大跳)下到底层(密集,小跳)。

## Use It

最常见的实际用途: 在向量数据库里找相似项。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"跟 item 0 最像的 Top 5: {top_k}")
print(f"相似度: {similarities[top_k]}")
```

你调 `model.encode(text)` 然后搜向量库,底层就是这玩意。嵌入模型把文本映成向量。向量库算你查询向量和每个存向量的余弦相似度(或点积),用 ANN 算法避免全比一遍。

## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Norm | "向量的大小" | 把向量映到非负标量的函数,满足三角不等式、绝对齐次、只在零向量处为零 |
| L1 norm | "曼哈顿距离" | 绝对分量值之和。优化时产生稀疏。对离群点鲁棒 |
| L2 norm | "欧氏距离" | 各分量平方和的平方根。欧氏空间的直线距离 |
| Lp norm | "广义范数" | 各分量绝对值 p 次方和的 p 次方根。L1、L2 是特殊情况 |
| L-infinity norm | "最大范数" 或 "切比雪夫距离" | 最大绝对分量值。Lp 在 p 趋向无穷时的极限 |
| Cosine similarity | "向量夹角" | 点积除以两个大小。范围 -1 到 +1。忽略向量长度 |
| Cosine distance | "1 减余弦相似度" | 把余弦相似度转成距离。范围 0 到 2 |
| Dot product | "未归一化余弦" | 分量乘积之和。等于余弦相似度乘两个大小 |
| Mahalanobis distance | "考虑相关的距离" | 在用数据协方差矩阵白化(去相关+归一化)过的空间里算 L2 |
| Jaccard similarity | "集合重叠" | 交集大小除以并集大小。用于集合,不是向量 |
| Edit distance | "Levenshtein 距离" | 把一个字符串变另一个所需的最少插入、删除、替换 |
| KL divergence | "分布之间的距离" | 不是真距离(不对称)。衡量用 Q 编码 P 损失的信息 |
| Wasserstein distance | "推土机距离" | 把一个分布搬成另一个的最少工作量。真度量 |
| Approximate nearest neighbor | "ANN 搜索" | 用 (HNSW、LSH、IVF) 之类算法找"差不多最近"的点,比精确搜快很多 |
| HNSW | "向量库算法" | 分层可导航小世界图。用于快速近似最近邻搜索的多层图 |
| L1 regularization | "Lasso" | 把权重 L1 范数加到 loss。驱权重到 0(稀疏) |
| L2 regularization | "Ridge" 或 "weight decay" | 把权重 L2 范数平方加到 loss。把权重往 0 缩,不稀疏 |
| Elastic Net | "L1 + L2" | 结合 L1 和 L2 正则。处理相关特征组比单独任何一个都好 |
