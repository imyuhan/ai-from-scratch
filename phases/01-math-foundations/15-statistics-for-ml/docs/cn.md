# 机器学习中的统计学

> 统计学告诉你模型是真有戏还是只是走运。

**Type:** Build
**Language:** Python
**Prerequisites:** Phase 1, Lessons 06 (Probability and Distributions), 07 (Bayes' Theorem)
**Time:** ~120 minutes

## Learning Objectives

- 从零算描述统计、Pearson/Spearman 相关、协方差矩阵
- 跑假设检验(t 检验、卡方)并正确解释 p 值和置信区间
- 用 bootstrap 重采样对任何指标构造置信区间,不用分布假设
- 用效应量把统计显著性和实际显著性区分开

## The Problem

你训了两个模型。模型 A 在测试集上 0.87。模型 B 0.89。你上线了模型 B。三周后,线上指标比之前还差。咋回事?

模型 B 实际上没超过 A。0.02 的差是噪声。测试集太小,或方差太大,或两个都有。你把"伪装成提升的随机性"上了线。

这种事天天发生。Kaggle 排行榜洗牌。论文复现不出来。A/B 测试靠几百个样本就宣布赢家。根因永远是同一个: 有人跳过了统计。

统计学给你工具区分信号和噪声。告诉你差异是不是真的、你该多自信、你要多少数据才能信一个结果。每条 ML 流水线、每个模型对比、每次实验都要统计。没它,你就是在猜。

## The Concept

### 描述统计:把数据压成几个数

建模前,得先知道数据长啥样。描述统计把数据集压成几个数,抓住形状。

**集中趋势**回答"中间在哪?"

```
均值:  所有值之和 / 个数
       μ = (1/n) * Σx_i

中位数: 排序后的中间值
       对离群点鲁棒。[1, 2, 3, 4, 1000] 均值 202,中位数 3。

众数:  出现最多的值
       类别数据有用。连续数据很少有用。
```

均值是平衡点。中位数是中间。当它们分开,你的分布是偏的。收入分布均值远大于中位数(右偏,来自亿万富翁)。训练 loss 分布常常均值远小于中位数(左偏,易样本太多)。

**离散度**回答"数据多散?"

```
方差:  到均值偏差平方的平均
       σ² = (1/n) * Σ(x_i - μ)²

标准差: 方差开方
       σ = sqrt(σ²)
       单位跟数据一样,更可解释。

极差:  max - min
       对离群点敏感。几乎从来不该单独用。

IQR:   Q3 - Q1 (四分位距)
       中间 50% 数据的范围。
       对离群点鲁棒。用在箱线图和离群点检测。
```

**百分位**把排好序的数据切成 100 等分。第 25 百分位(Q1)意思 25% 的值比它小。第 50 百分位是中位数。第 75 百分位是 Q3。

```
延迟监控:
  P50 = 中位延迟     (典型用户体验)
  P95 = 第 95 百分位   (差但不是最差)
  P99 = 第 99 百分位   (尾延迟,常常是中位数的 10 倍)
```

ML 里,你关心推理延迟、预测置信度分布、误差分布的百分位。平均误差低但 P99 误差可怕的模型,对安全关键应用可能完全不能用。

**样本 vs 总体统计。** 从样本算方差时,除以 (n-1) 而不是 n。这就是 Bessel 校正。它补偿"你的样本均值不是真实总体均值"这件事。除以 n 会系统性地低估真实方差。除 (n-1),估计就无偏了。

```
总体方差:  σ² = (1/N) * Σ(x_i - μ)²
样本方差:  s² = (1/(n-1)) * Σ(x_i - x̄)²
```

实际: n 很大(几千样本)时,差别可忽略。n 小(几十样本)时,有影响。

### 相关:变量怎么一起动

相关衡量两个变量之间线性关系的强度和方向。

**Pearson 相关系数**衡量线性关联:

```
r = Σ(x_i - x̄)(y_i - ȳ) / (n * s_x * s_y)

r = +1:  完全正线性
r = -1:  完全负线性
r =  0:  没有线性关系(可能有非线性的!)

范围: [-1, 1]
```

Pearson 假设关系是线性的,两变量都近似正态。它对离群点敏感。一个极端点就能把 r 从 0.1 拉到 0.9。

**Spearman 秩相关**衡量单调关联:

```
1. 把每个值换成它的秩(1、2、3、...)
2. 对秩算 Pearson 相关

Spearman 抓任何单调关系,不只线性。
如果 y = x³,Pearson 给 r < 1 但 Spearman 给 ρ = 1。
```

**啥时候用哪个:**

```
Pearson:    两变量连续,近似正态。
            你只关心线性关系。
            没有极端离群点。

Spearman:   序数数据(排名、评分)。
            数据不正态。
            你怀疑关系单调但不线性。
            有离群点。
```

**黄金法则:** 相关不是因果。冰淇淋销量和溺水死亡数相关,因为都在夏天涨。你模型的准确率和参数量相关,但加参数不一定涨准确率(参见过拟合)。

### 协方差矩阵

两变量的协方差衡量它们怎么一起变:

```
Cov(X, Y) = (1/n) * Σ(x_i - x̄)(y_i - ȳ)

Cov(X, Y) > 0:  X、Y 倾向一起涨
Cov(X, Y) < 0:  X 涨,Y 倾向降
Cov(X, Y) = 0:  没有线性共动
```

对 d 个特征,协方差矩阵 C 是个 d × d 矩阵,C[i][j] = Cov(feature_i, feature_j)。对角线 C[i][i] 是每个特征的方差。

```
C = | Var(x1)    Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)    Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)   |

性质:
  - 对称: C[i][j] = C[j][i]
  - 半正定: 所有特征值 >= 0
  - 对角 = 方差
  - 非对角 = 协方差
```

**跟 PCA 的关系。** PCA 对协方差矩阵做特征分解。特征向量是主成分(方差最大方向)。特征值告诉你每个成分抓多少方差。这正是 Lesson 10 讲的,现在你懂为啥协方差矩阵是对的东西要分解: 它编码了你数据里所有成对的线性关系。

**跟相关的联系。** 相关矩阵是"标准化变量"(每个除以自己的标准差)的协方差矩阵。相关把协方差归一化到 [-1, 1]。

### 假设检验

假设检验是在不确定下做决策的框架。先有个主张,收数据,看数据跟主张一不一致。

**设置:**

```
原假设 (H0):        默认假设,通常"没效果"
备择假设 (H1):      你想证明的东西

例子:
  H0: 模型 A 和模型 B 准确率一样
  H1: 模型 B 准确率更高
```

**p 值** 是"假设 H0 成立,看到的数据(或更极端)的概率"。它**不是** H0 成立的概率。这是统计学里最常被误解的一件事。

```
p 值 = P(数据这么极端 | H0 成立)

如果 p 值 < α(通常 0.05):
    拒绝 H0。结果"统计显著"。
如果 p 值 >= α:
    不能拒绝 H0。你证据不够。
    这不意味着 H0 成立。
```

**置信区间**给参数一个合理的范围:

```
均值 95% 置信区间:
    x̄ ± z * (s / sqrt(n))

z = 1.96 对应 95% 置信

解释: 如果你重复实验很多次,算出来的区间里 95% 包含真均值。
它**不**意味着"真均值有 95% 概率落在这个特定区间里"。
```

置信区间的宽度告诉你精度。宽 = 不确定。窄 = 你的估计精确(但如果数据有偏,精确不等于准)。

### t 检验

t 检验比均值。有几种。

**单样本 t 检验:** 总体均值跟一个假设值不一样吗?

```
t = (x̄ - μ_0) / (s / sqrt(n))

自由度 = n - 1
```

**两样本 t 检验(独立):** 两组均值不一样吗?

```
t = (x̄_1 - x̄_2) / sqrt(s1²/n1 + s2²/n2)

这是 Welch t 检验,不假设方差相等。
除非有特别理由假设方差相等,永远用 Welch。
```

**配对 t 检验:** 测量成对时(同一模型在同一数据划分上):

```
算 d_i = x_i - y_i 对每对
然后对 d_i 值跟 μ_0 = 0 跑单样本 t 检验
```

ML 里配对 t 检验很常用: 你在同一组 10 折交叉验证划分上跑两个模型,成对地比分数。

### 卡方检验

卡方检验看观测频数跟期望频数匹不匹。类别数据有用。

```
χ² = Σ(观测 - 期望)² / 期望

例子: 语言模型的输出分布跟训练分布在类别上匹不匹?

类别       观测     期望
正面         120      100
负面         80       100
χ² = (120-100)²/100 + (80-100)²/100 = 4 + 4 = 8

自由度 1 时,χ² = 8 给 p < 0.005。
差异显著。
```

### 模型的 A/B 测试

ML 里的 A/B 测试跟 Web A/B 测试不一样。模型对比有特定挑战:

```
1. 同一测试集:    两个模型必须在相同数据上评估。
                  不同测试集比没意义。

2. 多指标:        单看准确率不够。你要看 precision、recall、F1、延迟、公平性指标。

3. 方差:          用交叉验证或 bootstrap 估每个指标的方差,不止看点估计。

4. 数据泄漏:      如果测试集在模型选择时用过了,你的对比有偏。最后留一个测试集。
```

**流程:**

```
1. 定指标和显著性水平(α = 0.05)
2. 两个模型在相同 k 折交叉验证划分上跑
3. 收集配对分数: [(a1, b1), (a2, b2), ..., (ak, bk)]
4. 算差: d_i = b_i - a_i
5. 对差跑配对 t 检验
6. 查: 平均差是否显著不为 0?
7. 算平均差的置信区间
8. 算效应量(Cohen's d)判实际显著性
```

### 统计显著性 vs 实际显著性

一个结果可以统计显著但实际没意义。数据够多,微不足道的差异也会变显著。

```
例子:
  模型 A 准确率: 0.9234
  模型 B 准确率: 0.9237
  n = 1,000,000 测试样本
  p 值 = 0.001

统计显著? 是。
实际显著? 0.03% 提升不值得部署新模型的工程成本。
```

**效应量**量化差异有多大,跟样本量无关:

```
Cohen's d = (mean_1 - mean_2) / pooled_std

d = 0.2:  小效应
d = 0.5:  中效应
d = 0.8:  大效应
```

永远一起报告 p 值和效应量。p 值告诉你差异是不是真的。效应量告诉你有没有意义。

### 多重比较问题

检验很多假设时,有些会凭偶然"显著"。检验 20 样东西用 α = 0.05,啥都不是真的情况下你也期望有 1 个假阳。

```
P(至少一个假阳) = 1 - (1 - α)^m

m = 20 检验, α = 0.05:
P(假阳) = 1 - 0.95^20 = 0.64

你有 64% 概率至少一个假阳。
```

**Bonferroni 校正:** α 除以检验数。

```
调整 α = α / m = 0.05 / 20 = 0.0025

只有 p 值 < 0.0025 才拒绝 H0。
保守但简单。检验独立时好用。
```

ML 里,一个模型在多指标、试很多超参、跨多个数据集上评估时,这事就很重要。

### Bootstrap 方法

Bootstrap 通过"有放回重采样"你的数据来估计统计量的抽样分布。不用对底层分布做任何假设。

**算法:**

```
1. 你有 n 个数据点
2. 有放回抽 n 个样本(有些点出现多次,有些根本不出现)
3. 在这个 bootstrap 样本上算你的统计量
4. 重复 B 次(通常 B = 1000 到 10000)
5. bootstrap 统计量的分布逼近抽样分布
```

**Bootstrap 置信区间(百分位法):**

```
对 B 个 bootstrap 统计量排序
95% CI = [2.5 百分位, 97.5 百分位]
```

**Bootstrap 为啥对 ML 重要:**

```
- 测试集准确率是点估计。Bootstrap 给你置信区间。
- 你不能假设指标分布正态(尤其 AUC、F1、precision at k)。
- Bootstrap 适用于任何统计量: 中位数、两均值之比、两模型 AUC 差。
- 不用闭式公式。
```

**Bootstrap 用于模型对比:**

```
1. 你有模型 A、B 在同一测试集上的预测
2. 每个 bootstrap 迭代:
   a. 有放回重采样测试索引
   b. 在重采样集上算 metric_A 和 metric_B
   c. 存 diff = metric_B - metric_A
3. 差的 95% CI:
   [diffs 的 2.5 百分位, diffs 的 97.5 百分位]
4. 如果 CI 不含 0,差异显著
```

这比配对 t 检验鲁棒,因为它不对分布做任何假设。

### 参数 vs 非参数检验

**参数检验**假设特定分布(通常正态):

```
t 检验:         假设数据正态(或 n 大靠 CLT)
ANOVA:          假设正态和方差相等
Pearson r:      假设二元正态
```

**非参数检验**不对分布做假设:

```
Mann-Whitney U:     比两组(替独立 t 检验)
Wilcoxon signed-rank: 比配对数据(替配对 t 检验)
Spearman ρ:         秩上算相关(替 Pearson)
Kruskal-Wallis:     比多组(替 ANOVA)
```

**啥时候用非参数:**

```
- 小样本 (n < 30) 且数据明显不正态
- 序数数据(评分、排名)
- 重离群点没法剔除
- 偏态分布
```

**啥时候用参数:**

```
- 大样本(CLT 让检验统计量近似正态)
- 数据大致对称,无极端离群点
- 统计功效更强(更容易检出真实差异)
```

ML 实验里,你通常 n 小(5 或 10 折交叉验证),所以非参数检验像 Wilcoxon signed-rank 通常比 t 检验更合适。

### 中心极限定理:实际意义

CLT 说"样本均值的分布随 n 增长逼近正态",不管底层总体分布。

```
如果 X_1, X_2, ..., X_n iid 均值 μ 方差 σ²:

    X̄ ~ Normal(μ, σ²/n)   当 n -> 无穷

大多数情况下 n >= 30 就行。
高度偏态分布,可能需要 n >= 100。
```

**为啥对 ML 重要:**

```
1. 证明在聚合指标上用置信区间和 t 检验是合理的
2. 解释为啥跨交叉验证折取平均给出稳定估计,即使单折变化巨大
3. Mini-batch 梯度下降能用,因为批上平均梯度逼近真实梯度(CLT 在跑)
4. 集成方法: 多个模型的平均预测比单个模型更稳定
```

**CLT 不干的事:**

```
- 不让你的数据变正态。它让样本的均值变正态。
- 对重尾、方差无限的分布(Cauchy)没用。
- 对相关数据(无修正的时间序列)不适用。
```

### ML 论文里常见的统计错误

1. **在训练集上测试。** 必过拟合。永远留出模型训练时从没见过的东西。

2. **没有置信区间。** 只报一个准确率不带不确定性,让结果不可复现、不可验证。

3. **忽略多重比较。** 试 50 种配置报最好的那个,不做校正,假阳率爆表。

4. **把统计显著和实际显著搞混。** 0.01% 的准确率提升配 p 值 0.001 也没意义。

5. **在不平衡数据上用准确率。** 99% 负类的数据集上 99% 准确率,模型啥也没学到。用 precision、recall、F1 或 AUC。

6. **挑指标报。** 只报你的模型赢的指标。诚实的评估报所有相关指标。

7. **跨 train/test split 漏信息。** split 之前做归一化,或者用未来数据预测过去。

8. **小测试集不带方差估计。** 100 个样本上评估声称 2% 提升是噪声,不是信号。

9. **数据不独立时假设独立。** 同一患者的多个医学影像、同一文档的多句话。同组内的观测是相关的。

10. **p-hacking。** 试不同检验、子集、排除标准直到 p < 0.05。结果是搜索的人造物。

## Building It

你要实现:
1. **从零写描述统计**(均值、中位数、众数、标准差、百分位、IQR)
2. **相关函数**(Pearson 和 Spearman,带协方差矩阵)
3. **假设检验**(单样本 t 检验、两样本 t 检验、卡方检验)
4. **Bootstrap 置信区间**(任何统计量,不用假设)
5. **A/B 测试模拟器**(造数据、检验、查 I 类、II 类错误)
6. **统计 vs 实际显著性 demo**(展示大 n 让一切"显著")

全从零,只用 `math` 和 `random`。不用 numpy,不用 scipy。

## Key Terms

| Term | Definition |
|---|---|
| Mean | 所有值之和除以个数。对离群点敏感。 |
| Median | 排好序数据的中间值。对离群点鲁棒。 |
| Standard deviation | 方差开方。用原始单位衡量散布。 |
| Percentile | 给定百分比数据落在它下面的值。 |
| IQR | 四分位距。Q3 减 Q1。中间 50% 的散布。 |
| Pearson correlation | 衡量两变量线性关联。范围 [-1, 1]。 |
| Spearman correlation | 用秩衡量单调关联。 |
| Covariance matrix | 所有特征两两协方差组成的矩阵。 |
| Null hypothesis | 默认假设"没效果"或"没差异"。 |
| p-value | 原假设成立下,数据这么极端的概率。 |
| Confidence interval | 参数在给定置信水平下的合理范围。 |
| t-test | 检验均值是否显著不同。用 t 分布。 |
| Chi-squared test | 检验观测频数跟期望频数是否不同。 |
| Effect size | 跟样本量无关的差异大小。Cohen's d 常用。 |
| Bonferroni correction | 显著性阈值除以检验数,控制假阳。 |
| Bootstrap | 有放回重采样,估抽样分布。 |
| Type I error | 假阳。H0 成立但拒绝了。 |
| Type II error | 假阴。H0 不成立但没拒绝。 |
| Statistical power | 正确拒绝假 H0 的概率。Power = 1 - II 类错误率。 |
| Central limit theorem | 样本均值随样本量增长收敛到正态。 |
| Parametric test | 假设数据有特定分布(通常正态)。 |
| Non-parametric test | 不对分布做假设。基于秩或符号工作。 |
