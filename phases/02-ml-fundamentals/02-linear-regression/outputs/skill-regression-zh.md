# 回归策略指南

回归预测的是连续值。该用哪种方法,取决于"特征和目标之间的关系"、"特征数量"以及"过拟合风险"。

## 决策清单

1. 特征和目标之间的关系近似线性吗?
   - 是:从普通线性回归开始
   - 否:试试多项式特征,或换成非线性模型

2. 特征数和样本数的相对关系?
   - 少特征、多样本:普通线性回归就够用
   - 多特征、少样本:用正则化(Ridge 或 Lasso)
   - 特征数 > 样本数:Lasso(L1)做特征选择,或 Ridge(L2)整体收缩权重

3. 需要可解释性吗?
   - 需要:特征不多的线性回归,或用 Lasso 自动筛特征
   - 不需要:多项式特征,或直接上树模型 / 神经网络

4. 数据集小(1 万行以内)?
   - 用正规方程(闭式解)求参数,速度极快
   - 必须用交叉验证做可靠评估

5. 数据集大(百万行级)?
   - 用随机梯度下降(SGD)或小批量梯度下降
   - 正规方程会因 $O(n^3)$ 的矩阵求逆而跑不动

## 各种方法的适用场景

**普通线性回归(OLS)**:任何回归任务的基线。**先试它**。如果 R² 够用、模型也简单,就别折腾了。

**多项式回归**:散点图明显是曲线而不是直线。从二次(degree=2)开始,只有验证集效果支撑时才往上加,degree > 5 几乎一定过拟合。

**Ridge 回归(L2)**:特征多、且彼此相关。让所有权重向 0 收缩,但不会真的归零。适合"我觉得所有特征都贡献了一点"的情况。

**Lasso 回归(L1)**:特征多、且只怀疑少数几个有用。Lasso 会把不重要的特征权重**精确压到 0**,顺带完成自动特征选择。

**弹性网络(Elastic Net)**:L1 + L2 的组合。特征多、又彼此相关,同时想要部分特征选择时用。

## 常见错误

- 跑梯度下降前忘了做特征缩放(收敛会慢到怀疑人生)
- 用测试集表现去调超参数(应该用验证集或交叉验证)
- 拟合高次多项式却不看验证误差(训练集 R² 总会随次数增大而上升,不能信)
- 不看残差图(R² 看着高,但残差有规律 → 模型有系统误差,指标在骗你)
- 只看 R²(还应该看残差分布、MAE,以及业务上能接受的误差阈值)

## 速查表

| 方法 | 适用场景 | 正则化 | 特征选择 |
|------|----------|--------|----------|
| OLS | 基线、特征少 | 无 | 手动 |
| Ridge | 特征多、都有用 | L2(整体收缩) | 否 |
| Lasso | 特征多、只有几个有用 | L1(部分归零) | 自动 |
| Elastic Net | 特征多且彼此相关 | L1 + L2 | 部分 |
| Polynomial | 非线性关系 | 配合 Ridge/Lasso 用 | 手动选次数 |
